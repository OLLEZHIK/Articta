# Articta — Контекст проекта

## Суть
Articta — образовательно-аналитическая платформа. Пользователь не просто читает статью, а работает с ней: меняет входные параметры, получает пересчитанные результаты. Материалы = интеллектуальные инструменты, а не просто текст.

## Язык общения
Общаться с пользователем на русском языке.

## Стек (MVP)
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Markdown для контента
- Без базы данных, без авторизации

## MVP включает
- Главная страница
- Список статей
- Страница статьи
- Поиск
- Категории
- Markdown-рендеринг
- Связанные статьи

## MVP НЕ включает
- Авторизацию, комментарии, подписки
- AI-функции
- Редактор
- Базу данных
- Интерактивные компоненты (калькуляторы, графики — это Этап 2+)

## Категории и цвета
- Finance — синий
- Technology — бирюзовый
- Economics — зелёный
- Science — оранжевый
- Psychology — фиолетовый
- Business — тёмно-серый

## Дизайн
Ощущение исследования. Не блог, не Medium, не Википедия.
Ориентиры: Stripe Docs, Linear, Vercel, Notion, Apple.
Много воздуха, минимализм, акцент на типографику и контент.

## Принципы разработки
- Не переусложнять архитектуру
- Простое решение > сложное
- Не добавлять функциональность "на будущее"
- Чистый, понятный, расширяемый код
- Единый стиль проекта
- Читаемость > избыточная абстракция
- Основная ценность — контент и UX, а не техническая сложность

## Дорожная карта (для контекста, НЕ для реализации сейчас)
- Этап 2: Интерактивные блоки (калькуляторы, графики, таблицы)
- Этап 3: AI (вопросы к статье, генерация анализа)
- Этап 4: Fork статей (как GitHub для исследований)
- Этап 5: Сообщество авторов
